# Personal Portfolio Landing Page

A responsive one-page personal portfolio for U. Joshna Upendram showcasing bio, skills, projects and contact links.
It is built with semantic HTML5 and uses CSS Flexbox for the navigation and CSS Grid for the skills and project cards.
A media query makes it work on phones, and it is published for free with GitHub Pages.

**Live site:** https://YOUR-USERNAME.github.io/REPO-NAME/

## Structure
- `index.html` - semantic page structure (header, nav, main, sections, footer)
- `style.css` - styling, Flexbox/Grid layouts and the mobile media query
- `images/` - profile picture and other images
